01 / THE ENGINE

Small blocks.
Many streams.

Add requests, then step or run the scheduler. It reserves capacity for each admitted request, spends a token budget across running requests, and allocates physical KV-cache blocks as token counts cross a boundary.

Try filling the cache, then add one more request. It waits until enough cache is reserved to finish without evicting another request.

03 / HOW TO READ THIS

What the blocks mean.

A request has logical tokens, but its KV cache grows in physical blocks of eight. A partly filled block is reserved for that request. Colors show ownership; the cache is a shared pool.

BLOCKS NEEDED = ceil(total tokens / 8)
FREE = 40 - allocated blocks
